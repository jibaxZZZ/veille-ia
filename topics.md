# Sujets suivis (à modifier librement)

Plus un sujet est précis, plus les tests sont utiles. Retire ce qui ne t'intéresse pas, ajoute tes outils réels.

1. **Claude Code, Agent SDK, scheduled tasks (ex-routines), Managed Agents** : nouveautés, changements de limites et de politique d'abonnement ou d'API, nouveaux hooks, subagents, plugins.
2. **Hermes Agent (Nous Research) et LangGraph** : releases, plugins officiels, fournisseurs de modèles, règles et garde-fous ; compatibilité avec Claude Code.
3. **Harnais d'agents propre, perso et pro** : permissions, sandboxes, évaluation d'agents (rubrics, graders, outcomes), observabilité, reprise sur erreur.
4. **Automatisation du quotidien** : boîte mail, calendrier, MCP et connecteurs utiles, veille automatisée.
5. **Marché** : offres, prix, politiques d'usage, nouveaux modèles et concurrents des agents de code.
6. **Onboarding client automatisé** : parcours, UX, outils pour automatiser l'accueil et la configuration de clients.
7. **Inférence LLM en production** (veille seulement : cette machine n'a pas de GPU, donc aucun test de performance) : moteurs d'inférence, quantification, nouvelles architectures GPU. Retire cette ligne si hors sujet.

## Critères de pertinence pour la sélection

- Prioriser ce que Jibaxe peut mettre en œuvre cette semaine.
- Prioriser ce qui change une décision (coût, limite, compatibilité) plutôt que ce qui est seulement nouveau.
- Ignorer le bruit marketing sans fonctionnalité testable.
